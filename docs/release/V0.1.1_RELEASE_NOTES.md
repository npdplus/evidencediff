# PromptDiff v0.1.1 Release Notes

PromptDiff v0.1.1 is a naming and package-identity correction release for the local-first deterministic AI output comparison CLI.

## What Changed

- product identity: EvidenceDiff → PromptDiff;
- CLI command: `evidencediff` → `promptdiff`;
- workspace package namespace: `@npdplus/evidencediff-*` → `@npdplus/promptdiff-*`;
- package and CLI version: `0.1.0` → `0.1.1`;
- public README, documentation, examples, tests, and help text now use the intended PromptDiff identity.

## Behavior

There is no intended change to comparison semantics, deterministic checks, Regression/Improvement classification, Evidence format version `1`, verdict aggregation, exit codes, privacy posture, or local-first runtime behavior.

## Core Workflows

- `promptdiff compare` compares local Baseline and Candidate files and returns `REVIEW` when no deterministic acceptance checks are supplied.
- `promptdiff test` executes Test Definition format `1`, evaluates deterministic checks, classifies regressions/improvements, aggregates a verdict, and emits Evidence.

## Exit Codes

- `0` — `PASS`;
- `1` — `FAIL`;
- `2` — configuration/execution/runtime error;
- `3` — `REVIEW`.

## Historical Note

The v0.1.0 tag is retained as the historical initial release baseline. v0.1.1 restores the intended public product identity without rewriting Git history.
