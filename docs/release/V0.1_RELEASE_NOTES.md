# EvidenceDiff v0.1.0 Release Notes

EvidenceDiff V0.1 is a local-first CLI for comparing captured Baseline and Candidate AI outputs, running deterministic acceptance checks, classifying regressions, and producing versioned Evidence for developer review.

## Core Workflows

- `evidencediff compare` directly compares two local files and returns `REVIEW` because this workflow supplies no deterministic acceptance checks.
- `evidencediff test` executes Test Definition format `1`, evaluates deterministic checks, classifies regressions/improvements, aggregates a verdict, and emits Evidence.

V0.1 provides exact plain-text comparison, deterministic structural JSON comparison, order-sensitive arrays, distinct missing-vs-null behavior, and 12 deterministic checks: `json-valid`, `required-field`, `field-type`, `exact`, `contains`, `not-contains`, `regex`, `numeric-range`, `allowed-values`, `output-length`, `token-budget`, and `latency-budget`.

Difference is not automatically Regression. Baseline `PASS` → Candidate `FAIL` is the primary Regression transition; Baseline `FAIL` → Candidate `PASS` may be an Improvement.

## Evidence and Exit Codes

Evidence format version `1` is the canonical structured result. JSON is the canonical machine-readable serialization; console and Markdown are concise human renderings.

- `0` — `PASS`
- `1` — `FAIL`
- `2` — configuration/execution/runtime error
- `3` — `REVIEW`

Canonical JSON Evidence can contain diagnostic values and must be treated as potentially sensitive.

## Verified Examples

1. Structured JSON Regression — `FAIL`, exit `1`.
2. Prompt-Output Regression — `FAIL`, exit `1`.
3. Captured Model A vs Model B — `PASS`, exit `0`, with a Difference.
4. Token / Latency Budget Regression — `FAIL`, exit `1`.
5. Review-Only Direct Comparison — `REVIEW`, exit `3`.

## Local-First / Privacy

V0.1 consumes captured local outputs and supplied metadata only. It does not call model providers and has no provider API-key handling contract. Product runtime packages have no third-party runtime dependencies and require no network call after dependencies/build artifacts are available.
