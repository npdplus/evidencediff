# ADR-0007 — Local Files, No Database in V0.1

**Status:** Accepted

## Context
V0.1 requires local definitions, captured inputs, fixtures/examples, and reports but no shared history or collaboration.

## Decision
Use explicit local files; introduce no database requirement in V0.1.

## Consequences
Setup/privacy remain simple. A database is justified only by later proven requirements such as shared history, retention, indexing, collaboration, or hosted operation.
